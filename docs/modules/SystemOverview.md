# SystemOverview
系统概览
分类：Misc
描述：在 Apps 页面集中展示当前 Windows 系统和硬件运行概况。

## 需求
- 安全级别：常规模块
- 恶意标记：否
- 权限需求：无
- 驱动依赖：否
- 联网需求：否
- 开发状态：稳定
- 版本属性：普通可用

## 介绍
SystemOverview 是客户端内置的系统概览 App，也是 Apps 切换栏的第一个应用。启用模块后会自动打开 ClickGUI 并切换到 Apps 页的 System 标签。

页面顶部是欢迎区域，显示账户头像、用户名、本地日期与带秒时间、Windows 版本、开机时长、Jackal Client 版本、版本类型、实时帧率和已启用模块数量。

Privileges 区域展示 User、Admin、System 和 TrustedInstaller 四级进程身份。状态指示器会标出客户端当前所处级别，也可通过对应按钮请求切换；标题右侧提供 Privileges 模块快捷开关。

硬件区域采用响应式卡片布局：

- CPU：处理器名称、逻辑处理器数量、整体使用率和近期趋势，使用紫色强调色。
- GPU：当前桌面图形适配器、所有图形引擎的整体使用率和近期趋势。
- Memory：物理内存已用量、总量、可用量、使用率和近期趋势。
- Disk：所有固定磁盘的已用量、总量、可用量、磁盘数量和整体使用率。
- Network：当前主要活动网卡、实时下载/上传速度、链路速度和近期负载趋势。

硬件信息在后台异步采集，初次进入时不会阻塞界面；尚未返回数据的卡片显示加载动画。使用率数字、进度条及趋势会平滑过渡。卡片表面和边框会跟随 Neverlose 主题色；专业版还可在 Hardware Overview 标题右侧通过动画开关快速切换 Performance HUD。

Software Overview 根据当前模块状态显示活动软件：

- Game Detector 开启并检测到游戏时，显示游戏名称、Steam / 非 Steam 来源、程序图标、进程信息和 HH:MM:SS 格式的运行时间。
- SMTC 开启时，为每个有效媒体会话显示标题、艺术家、右上角来源和播放状态；有时间轴时会在进度位置显示当前时间、在最右侧显示总时长，并提供上一首、播放/暂停、下一首按钮。正在播放的会话会在背景显示平滑变化的象征性柱形图，暂停后柱形会缓慢回落。

内容区域会根据可用宽度和 GUI 缩放自动切换单双列布局，并支持鼠标滚轮、Home、End、PageUp 和 PageDown。

## 配置项
- Card Opacity (0~1)（卡片不透明度）
  类型：浮点数；默认：0.88
  说明：控制欢迎、权限、硬件和软件卡片背景表面的不透明度，不影响文字、图标、图表和控件。在 Neverlose 中，卡片背景还会乘以 GUI 的 NL Card Background Opacity (0~1)，前景内容不受该 GUI 设置影响。
- Card Brightness (0~1)（卡片亮度）
  类型：浮点数；默认：0.72
  说明：控制卡片背景表面的亮度，不改变硬件卡片各自的前景强调色。
- SMTC Visualizer Bar Width（SMTC 可视化柱宽）
  类型：浮点数；默认：6.0
  说明：控制媒体会话背景柱形图的柱宽，运行时限制为 2 至 30。
- Show Greeting（显示欢迎信息）
  类型：布尔；默认：true
  说明：控制顶部时间、日期和系统欢迎区域。
- Show Client Details（显示客户端详情）
  类型：布尔；默认：true
  说明：在欢迎区域显示 Jackal Client 版本、版本类型和实时帧率。
- Show Usage Graphs（显示使用率趋势）
  类型：布尔；默认：true
  说明：在硬件卡片中显示近期采样趋势。
- Refresh Interval (ms)（刷新间隔）
  类型：整数；默认：1000
  说明：系统状态采样周期，运行时限制为 250 至 10000 毫秒。

## 历史更新
- 1. 新增 SystemOverview 模块和 System App，支持系统欢迎信息、客户端信息及 CPU、GPU、内存、磁盘和网络概览。
- 2. System 移至 Apps 首位，新增账户会话、权限、游戏与 SMTC 媒体区域；硬件数据改为异步加载，并加入主题化卡片、加载动画、平滑进度与模块快捷开关。
- 3. 游戏卡片新增程序图标与大号运行时间；媒体卡片修复上一首图标，重新排列来源和时间轴信息，并补充动态中文字符加载。
- 4. 游戏运行时间调整为卡片高度的 60%，程序图标获取失败时回退为窗口图标；媒体会话新增可调宽度、平滑起伏并在暂停后缓慢回落的柱形背景。
- 5. 修复中文界面中标题、权限、游戏和媒体会话等文字显示为问号的问题。
- 6. 媒体柱形背景改为完整贴合卡片左右与底部边缘；播放中的媒体时间轴会在刷新间隔内连续推进，并支持按 H:MM:SS 显示一小时以上的时长。
- 7. 修复 Neverlose 卡片背景不透明度同时使文字、图标、图表和控件变淡的问题；该设置现在只影响页面与卡片背景。

## 备注
GPU 使用率依赖 Windows GPU Engine 性能计数器；系统或显卡驱动不提供该计数器时，页面仍会显示显卡名称，使用率保持最近一次有效值。

权限级别按钮可能触发客户端提权或重启；具体结果仍由 Admin、System 和 TrustedInstaller 模块及 Windows 权限策略决定。
