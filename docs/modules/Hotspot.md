# Hotspot
移动热点

## 模块简介

Hotspot（移动热点）用于开启 Windows 移动热点，并把客户端配置中的 SSID 名称、密码和频率段应用到系统热点设置。

## 使用方式

在 ClickGUI 的 Web 列中开启 `Hotspot` 模块。模块位于 `System Proxy` 下方。

开启后会异步尝试启用 Windows 移动热点；关闭模块时会异步尝试关闭移动热点，避免系统热点接口响应较慢时卡住客户端界面。若用户在 Windows 设置或其他程序中手动开关移动热点，模块开关状态会自动同步系统状态。

## 配置项

- SSID Name（SSID名称）
  - 移动热点显示的网络名称。
- Password（密码）
  - 移动热点密码，长度应为 8 到 63 个字符。
- Frequency Band（频率段）
  - 可选 `Any Available Frequency`、`2.4 GHz`、`5 GHz`。
  - 如果当前系统或无线网卡不支持指定频率段，模块会提示操作失败。
- Options Sync Cooldown (ms)
  - 开启模块时，同步系统热点配置到模块配置的间隔。
- Restart On Config Change
  - 开启后，在模块已启用时修改 SSID、密码或频率段会自动重启热点以应用新配置。
- Notify
  - 控制热点启停、配置应用和外部状态变化通知。

## 注意事项

- Windows 移动热点能力取决于系统版本、无线网卡、驱动和当前网络连接状态。
- 修改 SSID、密码或频率段后，已连接设备可能需要重新连接。
