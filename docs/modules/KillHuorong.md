# KillHuorong
杀火绒
分类：Process
描述：通过 KSwordARK 强制结束火绒安全相关进程。

## 需求
- 可用状态：可用（需要 KSwordARK Driver 扩展）
- 安全级别：恶意模块（高风险）
- 需要管理员权限：是
- 驱动依赖：是（KSwordARK）
- 是否需要联网：否
- 开发状态：稳定/常规
- 版本属性：普通可用

## 介绍
KillHuorong（杀火绒）会枚举固定清单中的火绒进程，并通过 KSwordARK 强制结束。驱动会在终止前清除目标的 PP/PPL 保护。

## 配置项
无（使用内置火绒进程清单）

## 备注
- 需要管理员权限和 KSwordARK 驱动。
- 火绒的自我保护、驱动和回调可能拦截终止；本模块只做进程终止，不移除其回调或驱动。
- 结束安全软件进程会降低系统安全性，并可能触发系统保护或安全软件自动恢复，请在隔离环境验证。
- 模块执行完成后自动关闭。
