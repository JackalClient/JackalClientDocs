## 介绍
Translator（翻译器）为翻译命令和其他调用统一翻译入口的功能提供在线翻译服务。
`/translate` 与 `/translatecopy` 直接使用本模块所选模式，不再先请求旧 QQ 翻译接口，避免额外的网络报错、等待及向其他服务发送原文。
适合在日常管理与自动化场景中按需启用。
初次使用可优先调整：Mode、DeepL Use Custom ApiKey、Niutrans Use EnvVar ApiKey: NIUTRANS_API_KEY。

## 配置项
- Module Status Auto Switch（模块状态自动切换）
 类型：布尔；默认：true
 说明：这是行为开关项。建议先按默认值使用，确认行为符合预期后再逐项启停，避免多个开关同时改动造成排查困难。
- Mode（模式）
 类型：枚举；默认："Edge"
 说明：选择翻译服务；Youdao 使用有道桌面客户端私有接口，无需填写 ApiKey，不依赖本机安装有道客户端。
 可选：Edge；Youdao（有道翻译）；DeepL；Niutrans（小牛翻译）；PearAPI；ApiHz；ApiHz 2；AI（人工智能）。
- AI Prompt（人工智能提示词）
 类型：文本；默认："将冒号后面的文本翻译成{lang}，直接输出即可，不要输出其他任何内容：\n{text}"
 说明：该配置用于调整模块行为细节。建议先按默认值运行，确认需求后再逐步调整。

## 备注
Youdao 为实验性私有接口，无可用性承诺，密钥、协议及限流策略可能变化。仅限个人学习研究；商业用途应使用官方开放平台。此模式不会在失败时自动向其他翻译服务发送原文。

指定目标语言时由有道识别原文，支持 `zh` / `zh-CN` / `zh-Hans` / `zh-CHS`（简体）、`zh-TW` / `zh-Hant` / `zh-CHT`（繁体）、`en`、`ja` / `jp`、`ko` / `kor` 等代码；未指定目标语言时沿用百度检测，中文译为英文，其他语言译为简体中文。

动态密钥仅在进程内缓存一小时，鉴权失败最多刷新重试一次；请求串行执行，连接超时八秒，取密钥总超时十五秒，翻译总超时三十秒。不完整的流式结果不会作为译文返回。

该模块可能受系统版本、权限级别、目标进程状态或安全软件策略影响；若功能未生效，优先检查管理员权限、驱动依赖、联网状态与系统兼容性。
