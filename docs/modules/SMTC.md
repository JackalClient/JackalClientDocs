# SMTC
系统媒体传输控制
分类：Misc
描述：接入 Windows 系统媒体会话，获取媒体信息并控制播放。

## 需求
- 安全级别：常规模块
- 权限需求：无
- 驱动依赖：否
- 联网需求：否
- 开发状态：稳定/常规
- 版本属性：Free / Pro

## 介绍
SMTC 模块读取 Windows 全局系统媒体传输控制会话，为歌词、音乐信息和媒体控制功能提供标题、艺术家、播放状态、进度与封面等数据。

媒体会话检测与其他功能同时查询进程时，进程查询缓存会同步保护读写，避免客户端运行一段时间后因并发访问而退出；过期记录会清理，缓存容量也有限制，减少长期运行时的内存积累。

## 配置项
- Pause/Resume Hotkey（暂停/继续快捷键）
 类型：快捷键；默认：空
 说明：优先暂停正在播放的最佳会话；没有正在播放的候选时，继续已暂停的最佳会话。
- Pause Hotkey（暂停快捷键）
 类型：快捷键；默认：空
 说明：只从正在播放的会话中智能选择并暂停。
- Resume Hotkey（继续快捷键）
 类型：快捷键；默认：空
 说明：只从已暂停的会话中智能选择并继续播放。
- Previous Media Hotkey（上一媒体快捷键）
 类型：快捷键；默认：空
 说明：智能选择当前媒体会话并切换到上一媒体。
- Next Media Hotkey（下一媒体快捷键）
 类型：快捷键；默认：空
 说明：智能选择当前媒体会话并切换到下一媒体。
- Pause All Hotkey（全部暂停快捷键）
 类型：快捷键；默认：空
 说明：暂停全部符合条件且正在播放的媒体会话。
- Hotkey Ignore Sessions Without Progress（快捷键忽略无进度的会话）
 类型：布尔；默认：true
 说明：开启后，所有 SMTC 播放控制快捷键都忽略不提供进度信息的会话。

## 相关命令
- `/smtc list`
- `/smtc pause [会话序号]`
- `/smtc resume [会话序号]`
- `/smtc prev [会话序号]`
- `/smtc next [会话序号]`
