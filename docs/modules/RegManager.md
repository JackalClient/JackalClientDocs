# RegManager
注册表管理器
分类：Registry
描述：在客户端内浏览、编辑、导出注册表项和值。

## 需求
- 安全级别：常规模块
- 权限需求：部分系统位置需要管理员权限
- 驱动依赖：否
- 联网需求：否
- 开发状态：维护中
- 版本属性：专业版

## 介绍
RegManager 是内置注册表管理器，可在 Apps 页面中浏览注册表树、查看当前键值列表，并支持复制、编辑、重命名、删除、创建和导出。

左右栏支持鼠标滚轮与滚动条浏览；当前交互焦点会根据选中项和鼠标所在栏判断。

## 交互
- 右键标签页、左侧树或右侧值列表可打开对应上下文菜单；标签页和树项支持加入或移出收藏夹，树项支持复制名称和双击展开或收起，有效路径值支持跳转到内置文件管理器、在资源管理器中定位及复制文件。
- 左侧树和右侧值列表支持使用 `Up` / `Down` 移动当前选中项目，并会平滑滚动到可见范围内。
- 按 `A-Z` 或 `0-9` 可跳转到以该字符开头的第一个项目；左侧树只在当前同级项目中跳转，右侧值列表在当前值列表中跳转。
- `F5` 刷新当前值列表和对应树分支；`Alt + Up` 选择上一级项，`Alt + Left` / `Alt + Right` 在当前标签页的浏览历史中后退或前进。
- `Ctrl + D` 收藏或取消收藏当前路径；`Ctrl + Shift + O` 打开收藏夹，`Ctrl + H` 打开当前标签页的历史记录。
- `Shift + Mouse Wheel` 可横向滚动当前栏。

地址栏空间不足时会优先压缩最长的路径段。右侧 `REG_SZ` 会按空值、GUID、有效路径和普通文本使用不同颜色，`REG_EXPAND_SZ` 与 `REG_MULTI_SZ` 也会分别高亮正文和分隔符。以 `@文件路径,资源编号` 表示的系统资源会在页面加载时解析，文本解析成功后直接替换对应名称或数据，悬停 1 秒后显示原始资源字符串。

## 配置项
主要视觉、滚动、列宽、标签页和注册表监控显示参数在 `Reg Manager` 模块配置中调整；`Navigation History Size` 控制每个标签页保留的浏览历史数量，默认 64。`Enable Resource Parsing` 控制资源解析，`Highlight File Paths` 控制文件路径高亮及相关快捷菜单，两项默认开启。

## 历史更新
- 优化右键菜单悬浮高亮位置和底部间距；改善左右栏悬浮边框显示；新增方向键和首字母/数字快速定位项目。
- 新增树箭头展开/收起动画、局部刷新、导航历史、长地址压缩、注册表资源预览及路径值快捷操作。
- 树展开状态会在后台自动保存，连续展开或收起不会阻塞界面操作。
- 新增收藏夹与历史记录共用弹窗，支持搜索路径、关键词高亮及快速跳转；收藏路径和每个标签页的历史记录会写入 Records.json。
- 弹窗关闭时 Esc 只关闭 RegManager 弹窗，不会关闭 Apps GUI。
- 收藏夹和历史列表支持滚轮、方向键、Home、End、Page Up 与 Page Down 浏览；历史路径按最近一次访问去重显示，弹窗打开时 Ctrl+Tab 优先切换收藏夹与历史标签。
