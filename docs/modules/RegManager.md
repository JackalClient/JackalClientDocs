# RegManager
注册表管理器
分类：Registry
描述：在客户端内浏览、编辑、导出注册表项和值。

## 需求
- 安全级别：常规模块
- 权限需求：部分系统位置需要管理员权限
- 驱动依赖：否
- 联网需求：否
- 开发状态：维护中
- 版本属性：专业版

## 介绍
RegManager 是内置注册表管理器，可在 Apps 页面中浏览注册表树、查看当前键值列表，并支持复制、编辑、重命名、删除、创建和导出。

左右栏支持鼠标滚轮与滚动条浏览；当前交互焦点会根据选中项和鼠标所在栏判断。

## 交互
- 右键左侧树或右侧值列表可打开对应上下文菜单。
- 左侧树和右侧值列表支持使用 `Up` / `Down` 移动当前选中项目，并会平滑滚动到可见范围内。
- 按 `A-Z` 或 `0-9` 可跳转到以该字符开头的第一个项目；左侧树只在当前同级项目中跳转，右侧值列表在当前值列表中跳转。
- `Shift + Mouse Wheel` 可横向滚动当前栏。

## 配置项
主要视觉、滚动、列宽、标签页和注册表监控显示参数在 `Reg Manager` 模块配置中调整。

## 历史更新
- 优化右键菜单悬浮高亮位置和底部间距；改善左右栏悬浮边框显示；新增方向键和首字母/数字快速定位项目。
