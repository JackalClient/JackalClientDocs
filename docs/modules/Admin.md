# Admin
管理员
分类：Combat
描述：重启客户端获得管理员权限。

## 需求
- 安全级别：常规模块
- 权限需求：无
- 驱动依赖：否
- 联网需求：否
- 开发状态：稳定/常规
- 版本属性：普通可用

## 介绍
立即重启客户端获得管理员权限。

## 配置项
- Exit After Run（运行后退出）
 类型：布尔；默认：true
 说明：该项会影响模块行为，建议基于默认值小步调整。
- bind（绑定）
 类型：按键/复合；默认：`Keybind(VK_RMENU, 'A')`
 说明：该快捷键用于即时触发功能。建议避免与系统或常用软件冲突。
## 历史更新
- v1.1.1：优化提权重启交接时的 Records.json 保存保护，避免旧进程覆盖新进程已更新的记录。

## 备注
如需客户端开启就获得管理员权限，请打开 `Config` 选项中的 `Always Admin 始终获取管理员权限`。
