# Scoreboard
记分板
分类：Render
描述：在屏幕上显示自定义文本记分板。

## 需求
- 安全级别：常规模块
- 权限需求：无
- 驱动依赖：否
- 联网需求：本地显示不需要联网；变量数据源另计
- 开发状态：稳定/常规
- 版本属性：普通可用；带 PRO 标记的阴影与变量功能需要 PRO

## 介绍
Scoreboard（记分板）在屏幕上显示自定义文本记分板。

## 全屏窗口隐藏

- `Hide In Fullscreen Window`（全屏窗口时隐藏）：布尔，默认 `true`。
- 开启后，前台窗口为无边框全屏或独占全屏时自动隐藏显示；退出全屏或切换到普通窗口后恢复。普通带标题栏的最大化窗口不会触发，支持多显示器。
- 此选项只隐藏画面，不关闭模块或停止后台功能；HUD Editor 开启时保留显示，便于编辑布局。
