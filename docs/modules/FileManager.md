## 介绍
FileManager（文件管理器）启用后进入文件管理器界面。（也可以在「应用」找到它）
我做的内置资源管理器。你可以使用它操作计算机上的文件。
初次使用可优先调整：File Enum Min Cooldown (ms)、File Enum Max Cooldown (ms)、File Attributes Update Cooldown (ms)。

专业版支持查看文件和目录的 NTFS 备用数据流（ADS）。文件列表可显示 ADS 数量标记或独立列；仅有 `Zone.Identifier` 时标为深蓝色，其他 ADS 标为红色。单选项目后，可在右键菜单中创建、导入、导出、通过专用剪贴板格式复制粘贴、重命名、清空和永久删除数据流；无现有 ADS 但剪贴板可粘贴时仍会打开管理子菜单。多选项目时，如果任一已扫描项包含 ADS，右键菜单可统一确认并批量清空。查看操作会在控制台输出前 1000 字节的文本与十六进制预览，截断时同时给出完整导出命令。删除数据流不会删除宿主文件，但数据流本身不能进入回收站。

## 标签页与列标题

标签栏以独立圆角标签、分界线和主题色选中标记显示。标签较多或窗口较窄时，左右箭头分页显示全部标签；新建、关闭、调整窗口宽度或通过快捷键切换标签后，会自动定位到当前标签所在页。新建按钮固定在标签栏右侧，不再被超出的标签遮挡；悬停翻页箭头可查看当前页码。

按住标签名称区域并横向拖动可调整顺序，原位置保留淡化虚影，目标位置显示高亮落点预览；停留在可用的翻页箭头上约半秒可跨页拖动。松开后才确认排序，在标签栏外松开则取消，排序不会改变当前打开的目录。关闭按钮使用 `acid_disable.png`，在当前标签或悬停时显示；名称会为关闭按钮和收藏标记预留空间，超长部分以末尾省略号显示。悬停名称可查看完整路径。

列标题需要横向移动超过拖动阈值，并越过相邻列的中点后才会换位；按下立即松开、轻微抖动或在标题栏外松开不会改变列顺序。

## 专业版文件大小可视化

`Calc Folder Size (PRO)` 默认 Off；Normal 在后台统计当前目录的全部文件夹，Prefer Everything 优先使用 Everything，缺失、不可用或无响应时回退普通统计，无需先选中文件夹。该选项放在 General 分组，不依赖大小可视化开关；开启后隐藏 `Calc Selected Folder Size`，选中项总大小自动异步复用后台统计结果。与大小可视化同时开启时，此选项决定共用统计方式，`File Size Visualizer Includes Folders` 仍控制文件夹是否参与比例柱。Off 仅关闭自动统计，不会禁用选中项或可视化发起的统计。

自动统计、选中项统计和大小比例柱共用文件夹大小缓存，同一路径正在计算时复用任务，不再重复遍历；更改选中项或切换标签页后，旧任务不会覆盖新选择的总大小。已计算好的文件夹会在启用 Size 列时显示大小，包括空文件夹的 `0 B`，即使可视化关闭也可显示；未计算的文件夹保留空白。缓存按规范化路径匹配并核对目录修改时间，切换目录或视觉模式不会清除已完成的统计结果。

File Size Visualizer (PRO) 在文件列表行背景绘制横向比例柱，按整个目录中已知大小的文件和可选的文件夹大小计算每个项目所占比例，不受滚动位置影响。文件先显示，文件夹统计完成一个显示一个；随着文件夹结果补齐，已有柱状条平滑调整占比，不等待所有目录统计结束。柱状条从左向右缓动展开；开启淡入时，在对应项目大小统计完成后逐渐显示不透明度。普通统计使用可取消的本地目录遍历，跳过无权访问的子目录，不递归目录链接；Prefer Everything 优先使用已索引文件夹的结果，仅对缺失的文件夹回退到普通统计。目录刷新不会重新播放已有项目的展开动画。

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `Calc Folder Size (PRO)` | Off | Off 不自动遍历；Normal 后台普通统计；Prefer Everything 优先复用索引、缺失部分回退普通统计 |
| `File Size Visualizer (PRO)` | Off | 关闭或使用 Bar 模式显示文件大小比例背景柱 |
| `File Size Visualizer Includes Folders` | Prefer Everything | Off 不统计文件夹；Normal 使用普通递归查询；Prefer Everything 优先使用 Everything SDK，无响应、查询被其他功能占用或失败时回退，部分目录未索引时仅补查缺失部分 |
| `File Size Visualizer Bar Color (File)` | White | 文件柱状条颜色 |
| `File Size Visualizer Bar Color (Folder)` | Gold | 文件夹柱状条颜色 |
| `File Size Visualizer Bar Opacity (0~1)` | 0.4 | 柱状条最大不透明度 |
| `File Size Visualizer Bar Fade In` | true | 对应项目大小统计完成后淡入柱状条 |
| `File Size Visualizer Visible Items Only` | false | 比例始终按整个目录统计；开启后，滚动使项目进入或重新进入视口时重播延伸动画；关闭后，所有项目共用首次入场时间，滚动不重播 |

## 收藏夹与历史记录

- 星形与时钟按钮位于工具栏右侧，与其它工具按钮在同一水平线上；收藏夹/历史标签、搜索框及列表样式与 RegManager 一致，关闭按钮支持悬停高亮。
- 使用 `Ctrl+D` 收藏或取消收藏当前目录，也可右键标签页或目录空白处操作。标签页右键菜单提供关闭和收藏/取消收藏，已收藏标签显示星形标记。
- 收藏夹与导航历史保存到客户端记录，可搜索、跳转和点击垃圾桶删除记录，不会删除实际文件。历史在所有标签间共用，进入目录及切换标签页都会记录访问路径，兼容旧版每个标签的历史记录。
- `Navigation History Size` 默认 100，历史按最近访问排列，并对目录去重。

## 专业版文件预览

恰好选择一个文件后按空格，在 App 内打开预览弹窗。目录和多选不会触发；再次按预览键、Escape 或右上角叉号关闭。弹窗采用与历史记录一致的边框和缩放淡入淡出动画，关闭按钮放大并支持悬停高亮；可拖动标题栏或拖动边缘/四角调整尺寸，鼠标光标提示当前操作。弹窗允许部分移出 App，只需保留一小块可拖拽标题栏在 App 内，绘制仍裁剪在 App 区域。预览期间，上下箭头和 Home/End 仍能切换选中的文件并刷新预览。切换 App、隐藏界面时停止播放并立即释放预览资源。

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `File Preview (PRO)` | 专业版开启、免费版关闭 | 专业版文件预览开关 |
| `File Preview Key` | Space | 可自定义预览快捷键 |
| `File Preview Types` | 全选 | 多选 Plaintext、Audio、Picture、Portable Executable |
| `File Preview Plaintext Max Size (KB)` | 10.0 | 只读文件开头片段，超出时显示橙色提示 |
| `File Preview Picture Max Size (MB)` | 5.0 | 超限图片在解码前拒绝读取 |

- 文本格式由 Ricochesta 的 `data/FilePlaintextFormats.json` 管理，客户端每次正常启动请求更新并缓存到 `output/Cache/ModuleMetadata`，下载失败保留有效旧缓存，不附带离线列表。支持扩展名、点文件名及无扩展名完整文件名，包含 `Makefile`、`.gitignore` 等；实际支持列表以云控为准。
- 支持 UTF-8、带 BOM 的 UTF-16 和系统本地编码；文本与 PE 报告支持鼠标拖选、Ctrl+A、Ctrl+C 和复制按钮，内容可滚动。高亮保留原文，支持不完整的预览片段。
- `.cpp .hpp .cppm .h .ixx .cxx .hxx` 使用 C++ 高亮；C、Java、Python 和 Markdown 保留原有高亮。
- `.json .json5 .jsonl .ndjson .hjson` 使用 JSON 配色，兼容逐行 JSON、注释、单引号及未加引号的键；高亮不是格式校验器，不重新排版原文。
- `.xml .xaml .user .vcxproj .filters .svg .hta .htm .html` 使用 XML 高亮，区分标签、属性、属性值、注释、声明、CDATA 和实体引用。
- `.wav .mp3`：使用紧凑的自适应弹窗，居中的播放/暂停键、平滑推进的可拖拽进度条，时间信息居中显示在进度条下方。Enter 切换播放/暂停；拖动时临时暂停，松开后定位并恢复原播放状态，未播放或播放结束后可从拖动的位置开始播放。安全读取上限为 256 MB。
- `.bmp .png .jpg .jpeg .webp .gif`：静态图片和 GIF 动画，滚轮缩放、左键平移；平移范围受约束，图片不能完全移出内容区域。
- `.exe .dll .sys .com`：使用 `/peparser` 相同报告格式展示基础信息、节区、导入与导出，读取上限与命令一致为 50 MB，不执行文件。
- 未支持或未勾选的类型使用较小弹窗，黄色提示居中绘制。图片上限和文本上限仅在开启对应预览类型时显示。
