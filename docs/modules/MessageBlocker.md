# Message Blocker
消息拦截器
分类：Window
描述：拦截目标窗口消息，并可输出消息记录和显示覆盖提示。

## 需求
- 安全级别：会改变目标窗口的消息处理，可能影响刷新、关闭与交互
- 权限需求：需要能够访问目标窗口；受目标进程权限与系统保护限制
- 驱动依赖：否
- 联网需求：否
- 开发状态：以当前构建支持情况为准
- 版本属性：普通可用

## 介绍

Message Blocker 用于拦截目标窗口的消息。使用前应先确认目标窗口，避免对系统关键窗口或有未保存内容的程序测试。

## 配置项

> 配置界面说明（v1.1.7）：WM_PAINT、WM_QUIT 与 WM_TIMER 忽略开关已合并为 `Ignored Messages` 多选项。
