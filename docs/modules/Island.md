# Island
灵动岛
分类：Render
描述：显示一个酷炫的灵动岛。

## 需求
- 安全级别：常规模块
- 权限需求：无
- 驱动依赖：否
- 联网需求：否
- 开发状态：稳定/常规
- 版本属性：普通可用

## 介绍
Island（灵动岛）用于显示一个酷炫的灵动岛。
适合在日常管理与自动化场景中按需启用。
初次使用可优先调整：Sync Status、Idle Components、Diversify Notify Icons。
Idle Icon Type 为 Normal 时，实际使用的贴图图标会在首次绘制时生成 mipmaps 并使用三线性过滤，无法生成多级 mipmap 时回退到双线性。该处理覆盖内置和自定义品牌图标，常驻 Idle 行同样生效；图标重新加载后会重新应用，不会每帧重复生成，原有尺寸、缩放和布局保持不变。
背景图片模糊会自动缓存；遇到过大的模糊纹理时会跳过磁盘导出，优先保证客户端不卡死。
开启 HUD Blur 与 Island 的 Background 后，灵动岛背景会按实际矩形与圆角接入 HUD Blur，包含常驻 Idle/歌词扩展区域和外置音频波形面板。支持 Legacy / Experimental，模糊随整体透明度与鼠标避让淡出；不会自动开启 HUD Blur。纯色背景不透明度过高或不透明背景图片可能遮住桌面模糊，可调低 Background Opacity 观察效果；背景图片模糊和切换模糊仍由各自选项独立控制。

Audio Wave (PRO) 为 Outside 时，外置波形面板先于灵动岛本体绘制，其阴影位于本体背景、图片及文字下方，不再覆盖灵动岛本体；Inside 模式的绘制顺序不变。
自定义背景图片支持中文等非 ASCII 路径；模块每次开启时会重新检查图片是否可用并按需重新加载。
与 BetterLyrics 联动显示歌词译文时，缺失译文会由 BetterLyrics 后台预取；网络异常时会自动降低翻译重试频率，避免长期运行时积累过多请求。
BetterLyrics 的 Mixed 显示模式也会作为灵动岛歌词来源处理，在保留 Mixed 其他输出的同时保持岛内歌词稳定显示。

空闲栏切换到歌词时，会保留正常的 Idle 内容与尺寸，直到歌词状态实际生效，不会因歌词缓存或切换等待缩成空白小圆球。恢复 Idle 时按当前空闲组件重新计算宽度，不会沿用歌词的宽度缓存。歌词暂时为空时，仅在歌曲确实播放且 BetterLyrics 仍向 Island 输出时回退显示歌名，歌名按实际文字计算尺寸；暂停后歌词被清理、来源关闭或没有可用歌词及歌名时恢复空闲栏。`Hide When Idle` 与按住快捷键隐藏仍按原配置生效。

Bili Video Helper 使用 Island 显示字幕时会独立占用岛内歌词区域，Better Lyrics 的普通输出、Mixed 输出及暂停歌曲的重复恢复不会覆盖字幕。字幕时长、逐字进度与译文独立读取视频时间轴；字幕刷新不影响 Desktop Lyrics 的歌曲滚动动画，退出字幕显示也不会清理 Karaoke 的歌曲内容。

ToastESP 的 Island 输出直接进入此通知布局，不再使用 `DIS_TEXT`，也不依赖 Notify 状态同步开关；WinRT 来源应用图标由 Broker 保存到客户端 `output/Cache/ToastIcons/`，灵动岛读取本地缓存。普通 Notify 的同步消息提供图片时也可显示。

## 全屏窗口隐藏

- `Hide In Fullscreen Window`（全屏窗口时隐藏）：布尔，默认 `true`。
- 开启后，前台窗口为无边框全屏或独占全屏时自动隐藏显示；退出全屏或切换到普通窗口后恢复。普通带标题栏的最大化窗口不会触发，支持多显示器。
- 此选项只隐藏画面，不关闭模块或停止后台功能；HUD Editor 开启时保留显示，便于编辑布局。
- 灵动岛沿用 `Hide When Idle` 的移出屏幕与恢复动画，此隐藏条件也适用于歌词、通知及其他非空闲状态。
