# ChatBar
聊天栏
分类：Render
描述：绘制一个聊天栏，可以显示控制台信息、IRC消息、直播弹幕等

## 需求
- 安全级别：常规模块
- 权限需求：无
- 驱动依赖：否
- 联网需求：否
- 开发状态：稳定/常规
- 版本属性：PRO 独有

## 介绍
ChatBar（聊天栏）用于绘制一个聊天栏，可以显示控制台信息、IRC消息、直播弹幕等。
支持文字与图片混排，并与同一行文字底部对齐；换行时图片保持完整，参与背景宽度计算、滚动、裁剪和淡出。高于字号的图片会撑高所在行，按实际行高计算滚动及背景布局。图片尚未加载或加载失败时，在预留区域显示文字替代内容，加载完成不会改变行宽；复制和搜索仍使用文字内容。
LiveChatter 的 `Emoji Renderer` 选择 `Image` 后，可在聊天栏显示弹幕表情图片。`Emoji Image Height Mode` 默认 `Smart`，将原高度限制在字号的 100%～200%；`Raw` 保留资源提供的原高度，`Uniform` 按当前字号等比缩放。`Emoji Opacity (0~1)` 默认 1，与聊天栏文字透明度、淡出及动画透明度相乘，只影响图片。图片异步下载、解码并分帧加载，缓存位于 `output/Cache/bili_emoji_<hash>.<实际格式>`，超过三天自动清理。LiveChatter 的 `Clear Emoji Cache When Disabled` 默认开启，关闭模块时同时清除内存与磁盘表情缓存，保留的聊天消息暂以文字占位显示。
LiveChatter 消息流的 `SC Notify` 选中 `Chat Bar` 后，会显示使用 SC 配色且带首尾边框的纯文字卡片，包含昵称、金额与留言正文，金额跟随 LiveStream 的 `Gift Value Display`，默认 Battery（电池），也可选 CNY（元）、Gold、Hamster 或 Silver。优先使用已有单位数据，缺失时按每元 10 电池 = 1000 金瓜子 = 1000 金仓鼠换算；电池与元保留小数且去除末尾多余的零（Off 或无对应价值的 Silver 隐藏金额），不加载 SC 图片。控制台输出使用同款卡片与配色。该输出独立于普通弹幕的 `Sync Live Chatters`，仍遵循聊天栏的淡出和历史显示规则。
ChatBar 会把仍在显示时间内的最后几行消息加密缓存到 Records.json，客户端重启或重新打开模块后可恢复这些消息；缓存会限制行数和文本长度，避免 Records.json 过大。
开启 `Sync Live Chatters` 时，ChatBar 同步的是 LiveStream 当前选择的 `Room ID` 中的直播弹幕；切换到别人直播间时，ChatBar 也应跟随该房间，而不是固定同步自己的直播间。

## 配置项

醒目留言卡片的标题独立占一行，上下边框按实际字体与换行后的正文像素宽度生成；调整字号、字体或聊天栏宽度后会重新适配，不使用控制台的字符列数计算边框。

- Remove Blank Lines（自动移除空白行）
 类型：布尔；默认：true；归入 Behavior 分组。
 说明：自动忽略没有文字或仅包含空白字符的消息行，包括空格、制表符、换行、全角空格和其他 Unicode 空白。判断基于移除 ANSI 控制码并解析颜色格式后的实际文本，覆盖控制台、IRC、直播弹幕、即时消息及缓存恢复。开启时也会清理显示列表和待显示队列中的现有空白行；关闭后保留新输入的空白行，不修改非空行的缩进或颜色。

> 配置界面说明（v1.1.7）：配置项按消息来源、布局、背景和行为分组，并按背景、阴影及旧消息淡出开关显示相关参数。
