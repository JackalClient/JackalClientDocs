 Jackal Client 命令

 请勿用于违法用途

----------------------------------------

命令行参数：

JackalClient.exe [--help] [--open] [--system] [--ti] [--admin] [--enable:<id1;id2;...>] [--shell] [--nostderr] [--nocolor] [--rtitle] [--protect] [--command command...] [--command-keep command...]


 --help
  -? : Show this help message and quit.
  
 --shell
 -s : Run JackalClient in immersive shell mode. CLIENT WON'T CREATE THE WINDOW. IF YOU WANT TO SHOW THE HUD, DON'T ADD THIS PARAMETER.
  
 --open
  -o : Open JackalClient after startup.
  
 --system
  -y : Run JackalClient as SYSTEM.
  
 --ti
  -t : Run JackalClient as TrustedInstaller.
  
 --admin
  -a : Run JackalClient as Administrator.
  
 --enable:<id1;id2;...>
  -e:<id1;id2;...> : Enable the specified modules at startup.
  
 --rtitle : Randomize the console window caption text.
 
 --protect : Enable the (self-)protection module.
 
 --command command... 
  -c command... : Execute the specified command after startup and quit.
  
 --command-keep command... 
 -k command... : Execute the specified command after startup and do not quit.
 
 --nostderr
 -n : Disable the standard error output.
 
 --nocolor
 -b : Disable the colorful output.
 
Launcher 命令行参数：

Launcher.exe [--launcher-help] [--apply-package <zip_or_tgz_path>] [--target-dir <dir>] [--start-client] [--client-args <args...>] [--kill-client] [--wait-client-seconds <n>] [--keep-package]

 --launcher-help
 --help : Show launcher command line help and quit.

 --apply-package <zip_or_tgz_path>
 --install-package <zip_or_tgz_path> : Run headless install mode, extract the package to target directory and replace client files.

 --target-dir <dir> : Override install target directory (default: launcher directory).

 --start-client : Start Release\\JackalClient.exe after install.

 --client-args <args...> : Extra command line arguments for JackalClient.exe (used with --start-client).

 --kill-client : Force kill JackalClient.exe before install if it is running.

 --wait-client-seconds <n> : Wait up to n seconds for JackalClient.exe to exit before install (default: 20).

 --keep-package : Keep package file after successful install.

统一说明：以下命令参数中，尖括号为<必选参数>，中括号为[可选参数]，省略号表示参数可以包含空格

命令：

/help [command...]
/helpraw [command...]
显示命令的帮助信息。如果不填参数则会输出命令行参数并打开本文件 COMMANDS.TXT。
如果填写参数，则会从该文件中显示所有匹配以该命令开头，以空行结尾的段落并输出。
而 /helpraw 在英文下不会翻译中文为英文。
示例：/help kill

/helprc <keyword...>
以 keyword 搜索命令语法，但是是向 Bilibili 直播间发送弹幕（只发送命令语法行）。


/helper [list]
显示所有的命令助手选项。命令助手选项，表示命令执行后可能会用到的相关命令，会自动加入这个列表。

/helper use <option_key>
使用键为 option_key 的命令助手选项。

/helper clear
清空命令助手选项。


/about
关于。

/async <command...>
异步执行一条命令。

/multiline <command...>
/ml <command...>
执行一条命令，命令可以多行。但是会打开一个输入框，你在里面编辑后按OK即可立即执行。

/multijackal <commands...>
/mj <commands...>
执行多条命令，用;;分隔，会依次执行，无论是否失败。每条命令的斜杠前缀可省略，例如：/mj notify test;;title test;;islandtip test

/multijackalinterrupt <commands...>
/mji <commands...>
执行多条命令，用;;分隔，遇到失败直接中止。每条命令的斜杠前缀可省略。

/jackaloutput <command...>
输出执行这条命令的输出。（测试命令）

/jackalspeak <command...>
讲述执行这条命令的输出。请避免执行输出过多的命令。
注意:
1. 只能获取到命令函数在返回前的输出，因为异步而在后面的输出并不能讲出来。
2. 无法获取命令函数调用的子进程的输出，例如执行一条CMD命令的输出（如果要读出一条CMD命令的输出，请使用/runspeak）


/ver
查看客户端和系统版本。

/when
输出当前时间的详细信息（本地时间、UTC、时间戳、时区、ISO/RFC 格式、周数、年内天数、今日进度、毫秒时间）。

/calendar [date/month/day/year]
输出日历。默认输出当月日历。
参数规则：
1. `year`：输出全年 12 个月日历（每行 4 个月，共 3 行）。
2. 其他参数均输出单月日历，支持格式：
   - `3.4` / `3/4`：当年 3 月，并高亮 4 日
   - `2027/1/1` / `2028.4.4` / `2030-4-1`：指定年月日，显示对应月份并高亮该日
   - `15`：当月并高亮 15 日
   - `April` / `六月`：指定月份
彩色规则：
1. 当日（Today）为红色。
2. 指定高亮日（Selected）为黄色。
3. 若当日同时为高亮日，使用紫色标记。

date: YYYY/MM/DD YYYY-MM-DD YYYY.MM.DD MM/DD MM-DD MM.DD
time: HH:mm:SS HH:mm

/encrypt <method> [content...]
/decrypt <method> [content...]
/encryptcopy <method> [content...]
/decryptcopy <method> [content...]
用指定方法加密或解密一行文本。
支持的方法，请输入字符串：
	base64
	md5
	crc32
	sha1
	beast
	beartalk
	urlencode
	abracadabra
	latin
	pipa
	pipaplus
	pipasimp: 简体
	pipatrad: 繁体
	pipasimpplus: 简体+
	pipatradplus: 繁体+
	pipasimpplus2: 简体+，带标点
	pipatradplus2: 繁体+，带标点
其中 beartalk 解密支持噪声容错：可自动忽略夹杂的空白、标点和无关字符（只提取有效映射字符）。
其中 beast 解密支持使用非标准字符集（使用自定义的四个字符都可以），会自动尝试解码。
其中 latin 解密仅支持使用文件或剪贴板的命令【即/decrypt(copy) latin，后面不带任何参数，或者/decryptf(c) latin <files...>】，防止控制台吞不可见字符。
若 content 不指定，则会先查看剪贴板里的文本，如果为空且为命令行线程，则直接要求输入。
后两条带copy的会将结果复制到剪贴板。

/encryptf <method> <files...>
/decryptf <method> <files...>
/encryptfc <method> <files...>
/decryptfc <method> <files...>
用指定方法加密或解密指定文件。files 支持双引号与多个文件。
/encryptf 与 /decryptf 直接替换原文件，/encryptfc 与 /decryptfc 会生成副本（file.txt -> file.encrypted.txt / file.decrypted.txt）。

/encryptml <method>
/decryptml <method>
多行加密/解密。输入命令后进入多行输入模式，单独一行输入 `::END::` 结束并执行。支持的方法与 /encrypt 相同。
latin 解密不支持使用/decryptml，请将要解密的内容复制后使用/decrypt latin命令。

/encryptor [content...]
/decryptor [content...]
没有参数时，切换加密器模块状态。否则，对 content 文本进行加密或解密。方式为加密器模块配置中选择的方法。

/abra [args...]
/abracadabra [args...]
/abracopy [args...]
/abracadabracopy [args...]
调用魔曰加密器进行指定的操作。由于魔曰原仓库开源协议的限制，Jackal客户端没有内置该功能，你需要单独下载一个开源的exe。路径需要在 Encryptor 加密器模块中设置。后两条带copy的命令会在成功后复制结果。args 填运行参数。填写/?查看帮助。提示：/abra -e/-d [-k <key>] -i <text...>

/report <hprocess/hwnd/path> <closeText> <description>
举报系统。
向 Windows Error Reporting (WER) 提交一条错误报告。目标可以是进程句柄/窗口句柄表达式或可执行文件路径。
示例：
 /report it
 /report 1234 "Game Client"
 /report "C:\\Windows\\System32\\notepad.exe" "Close" "Notepad"

/triggers add <name> [condition...]
创建触发器任务。如果 condition 不填则为空任务（永不触发）。任务名称不得重复。
免费版最多创建 6 个任务，专业版无限制。

/triggers rename <name> <newName>
重命名任务。

/triggers remove <name>
删除任务。

/triggers interval <name> [seconds]
查看或设置任务的条件检查冷却时间（秒）。不填则输出当前值。

/triggers enable <name>
/triggers disable <name>
启用或禁用任务。

/triggers list
/triggers info
展示所有任务的信息（名称、状态、属性、检查间隔、条件），彩色表格输出。
禁用的任务排在后面，以灰色显示。

/triggers attrib
输出所有支持的属性说明。

/triggers attrib <name>
输出指定任务的所有属性。

/triggers attrib <name> <flags...>
切换任务的属性。支持以下标志（每次可组合多个）：
  default       - 无冷却时间及限制
  cooldown [s]  - 触发后冷却 s 秒（不填则使用配置默认值）
  once          - 执行一次后自动禁用任务
  once_remove   - 执行一次后自动删除任务
  enabled       - 启用任务
  disabled      - 禁用任务
  enable_start  - 客户端每次启动时自动启用该任务

/triggers condition <name> [condition...]
查看或设置触发器的条件。不填则输出当前值。
条件由若干组件构成，组件之间为 AND 关系：
  on <YYYY-M-D|YYYY/M/D>        - 指定日期触发（月/日支持1~2位数字）
  on <weekdays>                  - 指定星期触发，多个用逗号分隔，例如 Mon,Wed,Fri
  at <H:mm|HH:mm|HH:mm:ss>      - 指定时间点触发（小时支持1~2位数字）
  during [dateStart] <timeStart> [dateEnd] <timeEnd>
                                 - 在时间段内持续触发，日期可选
  in <month_spec>[,<month_spec>...]
                                 - 指定月份触发（OR关系）。支持月份数字（1-12）、月份英文名/缩写（Jan/January等）、YYYY-M 或 YYYY/MonthName 指定年月，例如：2026/4,2027-Feb,October
  when <event>                   - 事件发生时触发
  unless <event>                 - 事件未发生时触发
  
支持的事件（event）：
  process_exists <pid|procname>  - 指定进程存在，支持进程ID和进程名。进程名可以不加.exe，不区分大小写
  process_ge <min> <procname>    - 指定进程数量 >= min
  process_le <max> <procname>    - 指定进程数量 <= max
  file_exists <path>             - 指定文件存在（含空格需加双引号）
  file_found <filename>          - Everything 搜索完全匹配文件名
  module_enabled <expr>          - 模块启用（& 表示与，| 表示或）。请填写去除空格的模块英文名称。大小写不区分。
  module_disabled <expr>         - 模块禁用（& 表示与，| 表示或）
  keybind_pressed <keybinds>     - 按键组合按下（逗号分隔，例如 LCtrl,LAlt,L）
  keybind_released <keybinds>    - 按键组合按下并释放
  bili_live_chatter <contains|is|startswith|endswith> <text>
                                 - 最近一条直播间弹幕满足条件（不区分大小写）
  jackal_output <command...> contains <keyword>
                                 - 执行客户端命令并检查输出中是否包含关键词（不区分大小写）
								   如果command/keyword包含空格，则需要使用英文双引号。
                                   注意：仅捕获 Jackal 原生命令通过 cout 输出的内容（如 /triggers list、/help 等）；
                                   系统命令（echo、dir 等通过 cmd.exe 执行的命令）的输出不会被捕获

/triggers action <name> [action...]
查看或设置任务的执行动作。不填则输出当前值。
支持以下动作格式（只能选一种）：
  command <cmd...>    - 执行客户端命令
  run <cmdline...>    - 异步执行 cmd 命令
  runps <cmdline...>  - 异步执行 PowerShell 命令

/triggers perform <name>
无视条件，立即执行指定任务的 action，并触发相关事件（once 属性会导致禁用等）。

/triggers execute <name>
无视条件，立即执行指定任务的 action，不触发相关事件。

/triggers clear
清除所有触发器任务。

/triggers clear enabled
清除所有已启用的触发器任务。

/triggers clear disabled
清除所有已禁用的触发器任务。

/triggers check <condition...>
立即评估给定条件，输出 true 或 false，不执行任何动作。可用于调试条件语法。

/steam <args...>
Steam相关命令。

/steam games
输出 Steam 注册表 Apps 下的游戏二维表，包含 AppID、中文名、是否安装、是否运行、是否更新

/steam installed
输出 Steam 注册表 Apps 下的已安装游戏二维表，包含 AppID、中文名、是否安装、是否运行、是否更新

/steam running
输出 Steam 注册表 Apps 下的正在运行游戏二维表，包含 AppID、中文名、是否安装、是否运行、是否更新
